# 0021. Webhook destination

Date: 2026-10-18

## Status

Accepted.

## Context

Owners want responses in their own systems too (a CRM, Zapier-style tools, their backend), without giving up the sheet. The platform must not keep response content, must not become a way to probe other networks, and must stay inside the Workers Free limits (ADR 0014).

## Decision

- **One webhook per form, in addition to the sheet.** It is configured in the Publish tab: an `https://` URL (no credentials, no IP address literals, no `localhost`, at most 2,000 characters). The sheet stays the destination of record; a failing webhook never holds back or fails the sheet delivery.
- **A separate queue message.** On a valid submission the API queues the usual sheet message and, when the form has a webhook, a second message with the same encrypted payload and the webhook's ID. The consumer handles webhook messages on their own: it decrypts the answers, builds the JSON body and POSTs it.
- **Body.** `{ "event": "submission.created", "formId", "formVersion", "submissionId", "submittedAt" (ISO 8601), "answers": { fieldId: value }, "fields": [{ "id", "label", "type", "value", "text" }] }`. `value` is the stored answer (option IDs for choices), `text` what the sheet shows (option labels). Receivers deduplicate on `submissionId`: delivery is at least once.
- **Signature.** Each form's webhook has a 32-byte secret, generated by the server and stored encrypted (envelope encryption, as tokens are). Requests carry `Freely-Signature: t=<unix seconds>,v1=<hex HMAC-SHA256(secret, "<t>.<body>")>`. The owner sees the secret when the webhook is created or the secret is rotated.
- **Delivery.** A 2xx answer is success. Redirects are not followed. 408, 429, 5xx, timeouts (10 s) and network errors are retried with the delivery backoff while the queue keeps the message (about a day on Workers Free); other 4xx answers are final. The webhook row keeps only metadata for the owner: last attempt, last success, last HTTP status, and whether it is failing. Nothing of the body is logged or stored.
- **Test.** "Send a test event" posts a sample body (marked `"test": true`) and shows the HTTP status, so owners can check their receiver.

## Consequences

- Response content leaves the platform to an address the owner chose, as it does to their Google Sheet.
- Each submission with a webhook costs one more queue message and one outbound request.
- More than one webhook per form, other events and field-level filtering can come later without changing the body format.
